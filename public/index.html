WHAT ARE WE ACTUALLY EVALUATING?

Six dimensions. One goal.

We analyze your Design System across 6 key dimensions to determine if it provides the right structure, information and technical evidence for AI agents to work with it effectively.

01

Access

Can an agent reach and retrieve the docs, components and tokens on its own?

02

Tokens

Can it discover and interpret design decisions encoded as tokens?

03

Components & API

Can an agent identify components and understand how they are configured?

04

Semantics

Can it understand when, why and when not to use something?

05

Patterns

Can it understand how components combine into larger patterns?

06

Documentation

Is there enough recoverable documentation for an agent to have real context?

THE DIFFERENCE

Humans can read a Design System. Agents need to be able to interpret it.

A design system is more than documentation. It's a set of components, rules, tokens and relationships. Agents need structured, technical and contextual information — not just human-readable text.

Human-readable
"Use Button for actions"
  • ✓General guidance
  • ✓Visual examples
  • ✓Natural language
  • ?Variants
  • ?API details
  • ?Semantic rules
Agent-readable
  • ✓Component identified
  • ✓Purpose identified
  • ?When not to use
  • ✓Variants
  • ✓API
  • ?Semantic rules
